# MIMO Receivers, Channel Capacity and Massive MIMO Receiver

Folder `massive_MIMO` for the Massive MIMO receiver BER vs SNR analysis for Maximal Ratio Combining (MRC) and Zero Forcing(ZF) receiver.

Folder `MIMO_performance` for Performance comparison of Zero Forcing (ZF) and Linear MMSE (LMMSE) receivers and Capacity comparison between equal power allocation and optimal (water-filling) power allocation.
